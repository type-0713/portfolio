## ⚡ Qanday Ishga Tushiriladi (Local Setup)

### 1-usul: Bir klik orqali ishga tushirish (Windows)
Fayllar ichidagi `start.bat` faylini ikki marta bosing. Brauzeringizda `http://localhost:3000` avtomatik ochiladi.

### 2-usul: Node.js orqali
```bash
# Repozitoriyni klonlash
git clone https://github.com/type-0713/portfolio.git

# Papkaga o'tish
cd portfolio

# Serverni ishga tushirish
node server.js
```
Brauzerda oching: [http://localhost:3000](http://localhost:3000)
